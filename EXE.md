# Utiliser CyberSleep.exe (sans Python)

Aucune installation nécessaire. Pas besoin de Python, pas besoin de modules.

## 1. Télécharger

Va dans l'onglet [Releases](https://github.com/ka3vo/Cyber-Sleep/releases) du repo et télécharge le fichier **`CyberSleep.exe`**.

## 2. Lancer

Double-clique sur `CyberSleep.exe`.

## 3. Si Windows bloque le fichier

Un message bleu **"Windows a protégé votre ordinateur"** peut apparaître. C'est normal, ce n'est pas un virus : c'est juste que le fichier n'est pas signé numériquement (ça coûte cher pour un petit projet perso).

Pour continuer :
1. Clique sur **"Informations complémentaires"**.
2. Clique sur **"Exécuter quand même"**.

## 4. Token Discord (optionnel)

Pour utiliser **Discord User Info** et **Discord Server Info**, le tool te demandera un token de bot au premier lancement, avec un guide intégré pour en créer un gratuitement en 2 minutes. Ce token reste enregistré en local, à côté du `.exe`, dans un fichier `token.txt` — jamais envoyé nulle part.
